# 🔑 Ключевые решения — статический сайт `static/`

> **Приняты, не переигрывать.** Перенесено из `MULTITICKET-STATIC.md` (раздел «🔑 КЛЮЧЕВЫЕ РЕШЕНИЯ»)
> перед удалением мультитикета. Мультитикет дублировал однофайловые тикеты из `tickets/`.
>
> Указатель в корневом протоколе: `AGENTS.md` → «🔑 Ключевые решения».

| # | Решение | Обоснование |
|---|---------|-------------|
| 1 | **Разделы программ = папки Яндекс.Диска** (`БОЕВЫЕ/ДЕТСКИЕ/ОБУЧАЮЩИЕ/ОЗДОРОВИТЕЛЬНЫЕ/ФУНКЦИОНАЛЬНЫЕ`). Хранится в `programs[].category` | Пользователь: «разделы программ — папка, в которой они сгруппированы» |
| 2 | Каждый раздел на странице программ — **сворачиваемая панель** (`<details>` или класс `.collapsible`) | Требование пользователя |
| 3 | Скрытие из выдачи — флаг `hidden: true` у программы/тренера. **Сейчас скрыты:** программа «Греко-римская борьба», тренер «Поторочин Станислав» | Требование пользователя |
| 4 | Скрытые объекты **не попадают** ни в `navPrograms/navTrainers`, ни в `programs.js/trainers.js`, ни в генерацию страниц | Иначе «скрыть» ничего не делает |
| 5 | Плитки на главной и на общих страницах — **только фото, заголовок, кнопки**. Текст — по клику (модалка или страница) | Требование пользователя |
| 6 | Расписание и цены — **картинками** (не таблицами). Все картинки кликабельны → **lightbox** | Требование пользователя |
| 7 | Ссылка на **BALLOO убрана** из футера | Требование пользователя |
| 8 | Текст новостей хранится в **markdown**. Ограничение 9999 символов считается **по видимому тексту без разметки** | Требование пользователя |
| 9 | Первые **200 символов** = короткий текст для предпросмотра. Если длиннее — новость разворачивается **в отдельном окне** (модалка) | Требование пользователя |
| 10 | **Админке нужен сервер** — в голой статике пароль и сохранение новостей невозможны. Решение: `scripts/admin-server.mjs` (Node, localhost) принимает изменения, пишет `db.json`, перегенерирует статику | Иначе «реальная функциональность раздела Новости» невыполнима |
| 11 | Пароль **не хардкодить** в коде и репо (правило AGENTS.md). Читать `process.env.ADMIN_PASSWORD`; значение лежит в `.env.local` (в `.gitignore`). Сессия 31: приоритет у `.admin-password.json` (sha256+salt), смена пароля в «Главных данных» | Правило №2 AGENTS.md |
| 12 | Фото, **не привязанные** к тренеру/программе, — на страницу **«Альбом»** | Требование пользователя |
| 13 | Фото с диска **не коммитятся как есть**: качаем в `static/data/`, оптимизируем (jpg/webp, ≤1600px, превью ≤400px) в `static/uploads/`, в `db.json` — только путь в `uploads/` | Исходники по 10–15 МБ, сайт не должен весить гигабайты |
| 14 | `Turbopack` запрещён, `next build --webpack` — не трогать. Статика к Next.js не относится и сборки не требует | Правило №1 AGENTS.md |
| 15 | **Один шаблон на тип сущности**, а не файл на каждую: `program.html?id=N`, `trainer.html?id=N`, `news.html?id=N`. Данные рендерит `js/entity.js` из уже существующих `js/data/*.js` | Отдельные HTML на 30 программ = дублирование и рассинхрон. Шаблон один — правка в одном месте |
| 16 | ~~Скрытый/несуществующий `id` в шаблоне → блок «Не найдено» + ссылка на общий список, а не 404~~ **ОТМЕНЕНО пользователем (сессия 35, тикет S141):** единая обработка «не найдено» — переделка `404.html` в каркас сайта + журнал `logs/404.log` + письмо на техпочту | Головая статика не отдаёт коды ответа → решение пересмотрено |
| 17 | Markdown рендерит `static/js/md.js` — один парсер на сущности и новости. `MD.plainText()` снимает разметку (для лимита 9999 и предпросмотра), `MD.preview(text, 200)` — короткий текст | Требование: теги разметки в лимит не входят |

## Решения пользователя волны 4 (Р1–Р3, сессия 33)

| # | Решение | Где применяется |
|---|---------|-----------------|
| **Р1** | Единое имя раздела — **«Коллектив»**, и оно становится **настройкой** (`settings.sectionNames` + API `get/save-section-names`), а не литералом в коде. Миграция: `homeSections[].title` → `sectionNames[]`, кроме `trainers` → «Коллектив» | 15 точек в `header.js`/`footer.js`/`entity.js`/`modal.js`/`trainers.html`/`trainer.html`/`index.html`; тикеты S127 (шаги 3–4), S128 (шаг 10), S133 (п.6) |
| **Р2** | Новость открывается **СТРОГО во всплывающем окне**: `news-item.html` **не создаётся**; `news.html?id=` открывает модалку + self-canonical / `og:type=article` / `NewsArticle`, при закрытии URL возвращается к `news.html` | Тикеты S129 (шаг 4), S133 (п.2, п.5); sitemap — только `news.html?id=` |
| **Р3** | Хост `https://центр-фр.рф` **подтверждён** (в XML sitemap — punycode через `url.domainToASCII()`). Динамическим делать **позже**: закладка `siteSettings.baseUrl` в S133 п.7, полноценное управление хостом — отложенный **S134** | Тикеты S133 (п.2, п.7), S134, S101 (проверка NGINX по обоим написаниям домена) |

## Прочие зафиксированные решения

| Решение | Обоснование |
|---------|-------------|
| `sitemap.xml` и `robots.txt` — **динамически генерируемые** артефакты `scripts/export-static.mjs` (+ общий модуль `scripts/lib/sitemap.mjs`), рукописными файлами не являются | Уточнение пользователя, сессия 32 (тикет S133) |
| Волна 4 **аддитивная**: функционал не сокращается, из структуры данных ничего не удаляется, новые поля опциональны с дефолтом = текущее поведение | «🔒 Правила волны», сессия 32 |
| Скрытые CRM-поля и `isDirector` на сайт **не выносятся** | Сессия 32 |
| Пароль админки в `db.json` **не попадает**; при смене пароля сессии сбрасываются | Сессия 31 (тикет S126) |
