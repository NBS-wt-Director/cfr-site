
# 🎯 Полный анализ проекта "Шифу Панда"

**Дата:** 2026

---

## 🗂️ Структура проекта

```
shifu-panda/
├── src/
│   ├── app/                    # Next.js App Router
│   │   ├── page.tsx            # Главная страница
│   │   ├── admin/              # Админ-панель
│   │   ├── contacts/           # Контакты
│   │   ├── programs/           # Программы
│   │   ├── schedule/           # Расписание
│   │   ├── trainers/           # Тренеры
│   │   ├── news/               # Новости
│   │   ├── lk/                 # Личный кабинет
│   │   ├── [slug]/             # Ручные страницы
│   │   └── api/                # API
│   ├── components/
│   │   ├── ui/                 # UI компоненты
│   │   ├── home/               # Компоненты главной
│   │   └── admin/              # Админ компоненты
├── public/uploads/            # Загруженные файлы
├── data/                      # Доп. данные
│   ├── pages.json              # Ручные страницы
│   └── footer.json             # Настройки футера
├── db.json                     # База данных
└── package.json
```

## ⚙️ Админ-панель

- Хедер, Слайдер, Расписание и Цены
- Тренировки, Программы, Сотрудники
- Новости, Страницы, Футер
- Контакты, Доп. контакты
- Разделы, Разделители
- Настройки, Статистика, Автозагрузка, Файлы

---

## 🔧 API

- `/api/db` - База данных
- `/api/programs`, `/api/trainers`, `/api/news`
- `/api/pages` - Ручные страницы
- `/api/upload` - Загрузка файлов
- `/api/admin/footer` - Настройки футера
- `/api/admin/pages` - Управление страницами

---

## 📝 Технологии

- Next.js 15, React 18, TypeScript
- Tailwind CSS + CSS Modules
- JSON база данных
- Яндекс.Диск для автозагрузки
- Lucide React иконки
