## Корневая причина

Вложенный `/* ... /* ... */` в CSS-комментарии на строках 83-89 style.css.
CSS-комментарии не вложенные → `*/` закрывает досрочно → мусор CSS → парсер
error-recovery ДРОПАЕТ правило `[hidden] { display: none !important }`.

**Это объясняет баг S40/S99/S109/S139/S141** — JS всегда был верным,
но CSS-правило не применялось.

- `style.css:83-90` — убран вложенный `/* */` из комментария
- `style.css:~2444` — добавлены 10 CSS-классов для страницы направления
