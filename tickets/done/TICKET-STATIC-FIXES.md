## 🐛 Раунд 2: выпадающие списки и модальное окно

### Найденные причины (реальные, а не симптомы)

| # | Причина | Симптом |
|---|---------|---------|
| 1 | JS ставил **inline** `menu.style.display='none'`. Inline-стиль перебивает CSS-правила `:hover` и `.dropdown-open` | Выпадашка «умирала» навсегда после первого клика мимо |
| 2 | `.modal-overlay { display: flex }` в CSS перебивал HTML-атрибут `hidden` | Модалку нельзя было закрыть крестиком и кликом мимо |
| 3 | Горизонтальное меню с выпадашками включалось только при `≥1024px`, а в мобильном меню выпадашек не было вовсе | «Выпадашек нет» при окне уже 1024px |
| 4 | `shortQuote()` бился: `replace(/'/g, "\'")` в JS — это просто `'`, экранирования нет | Поломанный `onclick` в карточках |
| 5 | `logo.png` лежал в корне `static/`, а ссылка — `uploads/logo.png` | Битая картинка логотипа |

### Исправления

**Выпадающие списки — теперь везде:**
- Desktop (≥768px): `<li class="dropdown">` + `<button class="dropdown-toggle">`, показ через CSS (`:hover` **или** класс `.dropdown-open`), JS только вешает/снимает класс
- Mobile (<768px): `<li class="m-group">` — аккордеон по тапу, те же пункты из данных
- Управление **только классами**, никаких inline-`style`
- `aria-expanded`, `aria-haspopup`, закрытие по `Escape` и клику вне шапки
- Брейкпойнт горизонтального меню опущен с 1024px до 768px
- На 768–1023px подпись кнопки «Заказать звонок» сворачивается в иконку, чтобы меню не переезжало

**Модальное окно:**
- Видимость через класс `.modal-overlay.open { display: flex }`, базовое состояние `display: none`
- Крестик: `type="button"` + `id="callCloseBtn"` + `stopPropagation()`
- Клик мимо окна: проверка `e.target === overlay`
- Клик внутри окна модалку НЕ закрывает

**Прочее:**
- `shortQuote()` → корректное HTML-экранирование (`&quot;`, `&#39;`)
- `logo.png` скопирован в `static/uploads/`
- Анти-кэш: все `css`/`js` подключены с `?v=3`

## ⚡ Раунд 3: разбиение данных по модулям

### Зачем
Единый `js/data.js` (10.7 КБ) грузился на каждой странице целиком, и правка одной новости
сбрасывала кэш всех программ и тренеров. Разбиение сделано **по потребителю**, а не по объекту:
страница подключает только модули тех секций, что на ней есть.

### Структура

```
static/js/data/
├── core.js       3090 Б  — всегда: контакты, настройки, разделитель + nav-срез
├── programs.js   4235 Б  — полные программы (описания, фото)
├── trainers.js   2540 Б  — полные тренеры
├── news.js       1919 Б  — новости
├── slider.js      969 Б  — слайдер (только главная)
├── schedule.js    436 Б  — картинки расписания
└── prices.js      359 Б  — картинка цен
```

### Ключевое решение: nav-срез
Меню в шапке нужно на **каждой** странице, но полные данные программ/тренеров там не нужны.
Поэтому `core.js` несёт лёгкий срез `navPrograms` / `navTrainers` (только `id` + `name`),
а `header.js` читает его с фолбэком:

```js
const programNav = data.navPrograms || data.programs || [];
```

Благодаря этому меню живёт на странице без единого тяжёлого модуля.

### Механика
- `core.js` объявляет `window.SITE_DATA` и ставит `null` в тяжёлых полях
- Модуль дописывает своё: `window.SITE_DATA.programs = [...]`
- `main.js` **не менялся**: проверка `if (!el || !data.programs) return;` уже корректно
  пропускает неподключённую секцию
- `index.html`: `core.js` первым, затем модули секций главной; версии `?v=4`
- Старый `static/js/data.js` удалён генератором, чтобы не перетирал `core.js`

### Проверка
- `node scripts/test-menu.mjs` → **23/23** (тест переведён на новую схему подключения)
- Отдельная проверка лёгкой страницы (только `core.js` + компоненты): меню — 15 пунктов,
  `programs-grid` пуст и не падает, `news-grid` показывает «Новостей пока нет», футер отрисован
- Все ресурсы отдают 200, `js/data.js` → 404

### Что это даёт на практике
| Страница | Было | Стало |
|----------|------|-------|
| Расписание | 10.7 КБ | core + slider + schedule ≈ 4.5 КБ |
| Контакты | 10.7 КБ | core ≈ 3.1 КБ |
| Главная | 10.7 КБ | все модули ≈ 13.5 КБ |

Плюс инкрементальный кэш: правка новости меняет только `news.js`, остальные файлы
остаются в кэше браузера.
