> **Статус:** 🔴 Активен (волна 5, первый в очереди)

> **Порядок волны 5:** **S137** → S138 → S139 → S134 → S135 → S140 → S141 → S142 → S101 (деплой)

## Постановка (дословно от пользователя)

«надо перестроить первую половину страниц конкретного тренера и
конкретного направления — обложку сделать по краю в верхнем левом углу, текст описания вокруг,
заголовок в самом верху по центру».

## Факты

1. `entity.js trainerBody` — вертикальный стек: фото (`.entity-cover`, 2:3) → ФИО → специализация → …;
2. `directions.js` — `.direction-head` двухколоночная (обложка + описание рядом), заголовок слева;
3. Прецедент обтекания уже есть: обложка новости в модалке (`news-cover-float`, `float:left`, 45%, S111).

## Шаги

1. Обе страницы: `<h1>` — первой строкой, **по центру** (`text-align:center`), над обложкой.
2. Обложка — **по левому краю контейнера** (`float: left`, ширина 40–45%, `margin: 0 1.5rem 1rem 0`,
   кадр 2:3 сохранить), описание и мета-строки **обтекают** справа. Мобильный (<768px):
   float снять, обложка на всю ширину (как в новости).
3. Всё, что ниже описания (плитки, расписание, цена, альбом, CTA) — после `clear: both`.
4. Общие классы (например `.entity-head-float`) для обеих страниц — не две разные разметки.

## Критерий готовности

На `trainer.html?id=` и `directions.html?id=` заголовок сверху по центру,
обложка у левого края, текст обтекает; на мобильном — стек; сетки ниже не съезжают.
