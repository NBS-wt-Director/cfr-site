## Цель/постановка

На главной странице в секции расписания при выборе вкладки «📋 Таблица»
вместе с таблицей отображаются картинки расписания.
Пользователь открывает вкладку «Таблица» — ему не нужна картинка.

## Корневая причина (НАЙДЕНА)

**Вложенный комментарий в CSS (строкa 83-89 style.css) ломал парсер:**

```css
/* ... margin: 0 5%;  /* S79: ширина как у слайдера */
} показывал картинки в режиме таблицы, S40) */
[hidden] { display: none !important; }
```

CSS-комментарии **НЕ ВЛОЖЕННЫЕ**. `*/` на строке 88 закрыл комментарий досрочно.
Строка 89 `} показывал картинки...` стала **мусором CSS**.
Парсер в error-recovery режиме **ДРОПНУЛ правило `[hidden]`** — оно физически
не применяется в браузере.

**Итог:** JS правильно ставит `grid.hidden = true`, но CSS-правила больше нет.
`.schedule-grid { display: grid }` продолжает показывать картинки.

Это объясняет, почему баг S40/S99/S109/S139 **повторялся ~9 раз** и никогда не чинился.
JS-код был ВЕРНЫМ всё это время.

## Также исправлено

2. **Страница направления:** CSS-классы `.direction-related`, `.direction-cta`,
   `.direction-count`, `.direction-subtitle`, `.direction-trainers`,

   без стилей (направление «Детские направления» выглядело как сплошной текст).

3. **Кэш браузера:** версия `?v=35` не менялась → браузер показывал старый кэш CSS/JS.
   Бумп `v=35 → v=36`.
