# S160 — Менеджер фотографий в «Настройках сайта»

> **Статус:** 🟢 Код готов (2026-11-12), локальная приёмка пройдена. Ждёт деплоя на прод.
> Поставлен 2026-11-11.

## Постановка (слова пользователя)

> «В "настройки сайта" добавь отдельный объект — менеджер фотографий:
> - шапка раздела справка: всего фото/используются/занято на диске
> - кнопка "удалить неиспользуемые" (удаляет те, что не выводятся (скрытые к показу, устаревшие))
> - дальше список всех фотографий с пометками использовано (при нажатии на метку — переход на страницу), скрыто, не использовано. если скрыто или неиспользовано — есть кнопка "удалить"
> - внизу кнопка "обновить данные"»

## Что реализовано

### Сервер (`scripts/admin-server.mjs`)

1. **`walkUploads(dir, relBase, out)`** — рекурсивный скан `static/uploads/` и `static/data/`
2. **`collectPhotoUsage(db)`** — обход всех разделов базы (`sliders`, `programs`, `trainers`, `news`, `directions`, `album`, `staff`, `halls`, `schedule`, `prices`, `siteSettings`) → `Map<relPath, usages[]>`
3. **`GET /api/admin/get-photo-manager`** — полный обзор: список фото с `status` (used/hidden/unused), `usages[]`, `bytes`, `mtime`; статистика; `missing_list` (битые ссылки в базе); scope: `uploads` | `data` | `all`
4. **`POST /api/admin/delete-photos`** — перенос в `trash/uploads/<timestamp>/`, `removePhotoRefs()` чистит все разделы базы, перегенерация статики. Защита: `used` файлы не удаляются без `force: true`

### Админка (`static/admin.html`)

1. **Новый раздел** `photo-manager` в сайдбаре (группа «⚙️ Настройки сайта»)
2. **Карточка-справка** — всего фото / используется / скрыто / не используется / занято на диске; осовободится при очистке; scope-статистика (uploads/data); битые ссылки
3. **Список фото** — превью, путь, размер, метка статуса (используется/скрыто/не используется), кнопка «Удалить» (для скрытых/неиспользуемых), клик по «используется» → переход на страницу сайта
4. **Кнопка «🧹 Удалить неиспользуемые»** — сбор всех unused → подтверждение → удаление чанками по 200
5. **Кнопка «🔄 Обновить данные»** — перезагрузка с сервера
6. **Scope select** — фото сайта / рабочий архив / все каталоги
7. **Фильтры** — все / используется / скрыто / не используется
8. **Поиск** по пути файла
9. **Пагинация** — назад/вперёд, per_page=48
