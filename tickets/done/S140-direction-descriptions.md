# S140 — Генерация описаний для направлений без описания

> Закрыт: 2026-11-07, выполнено — скрипт gen-direction-descriptions.mjs, 4 направления заполнены, идемпотентен.

> **Статус:** 🔴 Активен (волна 5, шестой в очереди — после S134/S135)

> **Порядок волны 5:** S137 → S138 → S139 → S134 → S135 → **S140** → S141 → S142 → S101 (деплой)

## Постановка (дословно от пользователя)

«для направлений у которых нет описания сгенерируй,
отталкиваясь от описаний входящих в него программ».

## Факты

У 5 из 7 видимых направлений (`dir-0…dir-4`) `description` пуст (S131 п.3).

## Шаги

1. Скрипт `scripts/gen-direction-descriptions.mjs`: для каждого направления без описания
   собрать описания программ состава (`programs[].description`, markdown), сжать
   (общие темы, возраст, формат) в 2–4 предложения markdown. Без LLM-сервисов —
   эвристическая сборка (первые предложения + возрастные диапазоны + перечисление программ);
   текст должен читаться как человек и не выдумывать факты (нет данных — не писать).
2. Писать **только** в пустые `description` (неперезапись правок админа), `--dry-run` обязателен.
3. После генерации — `npm run static:export`; админ может отредактировать в «📁 Направлениях».

## Критерий готовности

Пустых описаний у видимых направлений не осталось; сгенерированное
не противоречит описаниям программ; повторный запуск ничего не меняет.
