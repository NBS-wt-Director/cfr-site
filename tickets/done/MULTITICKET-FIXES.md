**Что нужно сделать:**

1. Создать API для запуска миграции:
   ```
   POST /api/admin/data/transition
   → returns { taskId: "abc123", stages: [...] }
   ```

2. Создать API для получения прогресса:
   ```
   GET /api/admin/data/transition/:taskId/status
   → returns { taskId, stages, completed: boolean }
   ```

3. Сохранять taskId в localStorage:
   ```javascript
   localStorage.setItem('migrationTaskId', taskId);
   ```

4. При загрузке страницы проверять localStorage и продолжать polling:
   ```javascript
   useEffect(() => {
     const taskId = localStorage.getItem('migrationTaskId');
     if (taskId) startPolling(taskId);
   }, []);
   ```

5. После завершения — удалять taskId из localStorage:
   ```javascript
   localStorage.removeItem('migrationTaskId');
   ```

**Критерии готовности:**
- [ ] Кнопка запускает миграцию и получает taskId
- [ ] Прогресс отображается по этапам (running/success/error)

- Извлечение скидки из части до `"пм - "`

- Группа сохранять как есть (не разбивать)

**Дополнительно:**
- Сопоставление пользователей с данными:
  - В `data.xlsx` колонка `Клиент` содержит ФИО клиента (с возрастом)
  - Нужно сопоставлять по ФИО (без возраста)

  - Дубликаты пользователей не создавать
- **Посещение:**
  - `visit_date` — значение из колонки `Посещение`

  - Если колонка `Оплачено` есть значение (не пусто) — это **оплата**
  - Формат значения: `"50%, пм - 360"` или `"без %, пм - 720"` или `"пм - 360"`

  - **Извлечение скидки:** часть до `"пм - "` (например `"50%, "` или `"без %, "`) сохранять в `discount`
  - Если скидки нет — поле пустое
  - `payment_date` — дата (если есть в `Посещение`, иначе текущая дата)
- **Долг:**
  - Сохранять как есть по знаку:
    - Отрицательное значение — сумма долга
    - Положительное значение — остаток / переплата
  - Не переинтерпретировать, не менять знак

**Критерии готовности:**
- [ ] Парсер посещений/оплат создаёт записи в `user_visits` и `user_payments`
