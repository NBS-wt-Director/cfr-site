# ✅ done — выполненные тикеты

Сюда **переносятся** файлы тикетов после их полного выполнения.

## Правила переноса

1. Тикет считается выполненным, если:
   - выполнены все шаги и **критерий готовности**;
   - в теле тикета записана строка закрытия;
   - проверки (тесты) зелёные.
2. Файл переносится из `activ/` (или `definded/`) в `done/` **без изменения текста**;
   в шапку добавляется строка: `> **Закрыт:** <дата>, <сессия/команда>. <итог в одну строку>`.
3. В индексе `tickets/README.md` строка тикета перемещается в таблицу «Выполненные».
4. Спорные тикеты, закрытие которых подтверждено (проверкой кода/тестов), тоже переносятся сюда
   с пометкой, чем подтверждено закрытие.
5. Массовый перенос — по команде **«приберись в задачах»**.
