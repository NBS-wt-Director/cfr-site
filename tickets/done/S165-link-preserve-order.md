# S165 — Исправление: ссылки при сохранении слайдов перепутаны

> **Статус:** 🕐 В разработке (2026-11-12).
> Поставлен 2026-11-12.

## Постановка (слова пользователя)

> «Ссылки при сохранении перепутаны.»

## Описание проблемы

При пакетном редактировании слайдов (особенно полей `link`/`linkTarget`) — ссылки могут сохраняться некорректно:
- Ссылки перемешиваются между слайдами
- `linkTarget` теряется
- Порядок слайдов может нарушиться

## Возможные причины

1. **`sanitizeSlides` не сохраняет порядок** — если используется `Set` или `Map`, порядок может нарушиться
2. **ID не совпадают** — если `id` генерируется заново (`Date.now() + out.length`), то порядок может сломаться
3. **Дубликаты ID** — если два слайда получают одинаковый ID, один затрётся

## Что нужно

1. Проверить `sanitizeSlides` — порядок должен сохраняться
2. Проверить, что `id` не пересоздаётся для существующих слайдов
3. Добавить тест: 10 слайдов с разными ссылками → все ссылки на местах
4. Добавить визуальную индикацию: если ссылка невалидна — подсветить красным

## Критерий готовности

- [ ] `sanitizeSlides` сохраняет порядок слайдов
- [ ] `id` не пересоздаётся для существующих слайдов
- [ ] Тест: пакетное сохранение 10 слайдов → все ссылки на местах
- [ ] Валидация ссылки: подсветка невалидных
