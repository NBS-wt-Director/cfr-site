## Постановка (слова пользователя)

1. **Плитки расписания (чипы `week-chip`)** — при клике они чуть увеличиваются и
   появляются 3 кнопки:
   - **«Подробнее»** — переход на страницу программы;
   - **«Посмотреть»** — если у программы есть отдельный фотоальбом (если нет — кнопка скрыта);
   - **«Записаться»** — открывает форму обратной связи, в скрытое поле «причина»
     записывается: тренировка, на которой вызвали форму + страница вызова
     (админу понятно, куда/что хочет клиент и какова мотивация).
2. **Отдельная БД запросов обратной связи**: все вызовы формы пишутся туда.
3. **Админка**: подраздел `CRM → Вызовы форм обратной связи` — список заявок
   со статусами: `Новая → Звонок → Объяснено → Клиент_пришёл_на_первую → Клиент_ходит`.

### Форма обратной связи
- `static/js/modal.js` — `window.openCallModal(place)`:
  - причина строится `buildReason(place)` = `«<Место> — <Страница>. Есть вопрос...»` (S104);
  - POST на `/api/send-email` ⚠️ **ЭТОГО ЭНДПОИНТА НЕТ В admin-server.mjs**
    (grep не нашёл) → сейчас форма ВСЕГДА падает в mailto-fallback;
  - payload: `{ name, phone, email, message, reason }`.
- NGINX (`deploy/nginx-site.conf` стр. 49): проксирует **только `/api/admin/`** →
  публичный эндпоинт заявок должен быть в префиксе `/api/admin/`
  (как `log-404` — без токена, пример: `handleLog404` стр. 2894).

### Админ-сервер (scripts/admin-server.mjs)
- Роуты объявлены блоком в `http.createServer` (стр. 3161+), паттерн:

   - клик по чипу НЕ ведёт сразу на программу: чип получает класс `chip-open`
     (чуть увеличивается: `transform: scale(1.06)` + z-index), под/внутри чипа

       - «Подробнее» → `program.html?id=<programSlug||programId>`;

       - «Записаться» → `openCallModal('Расписание — <день> <time> — <program>')`
         (место = тренировка + страница вызова; страница вызова уже добавляется

- Клик по чипу расписания: чип чуть увеличивается, видны 3 кнопки;
  «Посмотреть» отсутствует у программ без альбома.
- «Записаться» открывает форму; в заявке (leads.json) видны тренировка и страница вызова.
- В админке CRM → «Вызовы форм обратной связи» список заявок, статусы меняются
  и сохраняются, новые первыми.
- `leads.json` не участвует в static:export и деплой-мерже; бэкапится в backups/.
- Тесты S151 зелёные.
