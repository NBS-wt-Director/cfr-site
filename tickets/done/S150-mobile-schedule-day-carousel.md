# S150 — Мобильное расписание: 1 день + карусель дней ✅

> **Закрыт: 2026-11-09** (проверка: `npm run test-static`, тесты S150)

## Постановка (замечание администратора, проверка на мобильном)

Табличное расписание на мобильном «странное» (7 колонок / широкая таблица с
горизонтальным скроллом). Решение пользователя: **везде показывать 1 (текущий)
день недели и переключать дни слайдером по карусели** — по всему расписанию.

## Факты

Расписание рендерится в трёх местах, все через `static/js/schedule-ui.js`:
- главная, режим «Таблица» → `weekBoard()` (main.js:118);
- страницы программ/тренеров («Мои тренировки») → `table()` / `boardOrTable()` (entity.js);
- страница направления → `weekBoard()` (directions.js:199).

Старый мобильный стиль S80 (горизонтальный скролл 7 колонок, `scroll-snap`) — заменён.

## Решение

**JS (`schedule-ui.js`):**
- `todayIndex()` — текущий день (Пн=0…Вс=6), `dayTabs()` — вкладки Пн…Вс
  (активная = сегодня при рендере);
- `weekBoard()` — вкладки + `data-day-idx` на колонках + `day-active` у сегодняшней;
- `table()` — строки сгруппированы в 7 `<tbody class="sched-day-body" data-day-idx>`,
  пустые дни — `<tr class="sched-day-empty">` («Нет занятий в этот день»);
- `initDayCarousel()` — делегированные обработчики на document: клик по вкладке,
  свайп touchstart/touchend (порог 40px) на `.week-board-wrap` / `.schedule-table-wrap`;
  вызывается при загрузке модуля (работает и для DOM, отрисованного позже).

**CSS (`style.css`, блок в конце файла — перебивает базовый `min-width:1050px` доски):**
- на ≤767px: `.week-day-tabs` — flex-строка со скроллом; `.week-col`/`.sched-day-body`
  скрыты, `.day-active` — показ; `.schedule-table` без `min-width`;
- на десктопе: вкладки `display:none`, пустые дни скрыты — вид как раньше (7 колонок /
  единая таблица).

Базовая высота таблицы `tr:nth-child(even)` — сохранена по tbody.
