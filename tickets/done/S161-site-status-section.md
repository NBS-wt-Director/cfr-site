# S161 — Раздел «📟 Статус» в админке

> **Статус:** 🕐 В разработке (2026-11-12).

## Постановка (слова пользователя)

> «В "настройки сайта" добавь раздел "статус" куда выводится полное состояние сайта + состояние сервера + посещаемость за день/неделю/месяц/год общая/по разделам/по страницам»

## Что должно быть

### 1. Состояние сайта
- Версия кэша `?v=47`
- Количество слайдов / программ / тренеров / новостей / направлений
- Размер `db.json` на диске
- Размер `static/uploads/` на диске
- Размер `static/data/` на диске
- Количество фото (всего / используется / скрыто / не используется)
- Ссылки на разделы: Слайдер, Менеджер фото, Статус

### 2. Состояние сервера
- PID и uptime админ-сервера (port 3456)
- PID и uptime PM2 (если есть)
- Использование CPU / RAM процесса Node
- Диск: свободно / занято (root, /home)
- Память: total / used / free
- NGINX: жив / мёртв (проверка 80/443)
- Версия Node.js
- Версия ОС

### 3. Посещаемость
- Визиты за день / неделю / месяц / год (общее число)
- По разделам: главная / программы / тренеры / новости / расписание / цены / альбом / контакты
- По страницам: top-20 страниц за период
- График (если возможно)

## Что уже есть в базе

- `db.json` → `visits[]` — пустой массив (заготовка, не используется)
- `logs/404.log` — локальные логи 404
- `logs/leads-email.log` — логи почты
- `leads.json` — заявки обратной связи
- NGINX access log отключён (`access_log off`)

## Что нужно сделать

1. **Трекер посещаемости** — пиксель на страницах сайта, серверный учёт визитов

3. **API `/api/admin/get-visits`** — визиты за период (день/неделя/месяц/год), по разделам, по страницам
4. **Раздел «📟 Статус»** в `admin.html` — карточки с данными
5. **Тесты** в `test-static.mjs`
