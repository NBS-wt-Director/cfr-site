## 🔴 КРИТИЧЕСКИЕ ТИКЕТЫ (для реализации)

### Тикет 1.4-A: DB-Trigger-Updates (раздел 11.3)

**Приоритет:** 🔴 Критический
**Сложность:** Средняя
**Описание:** Реализовать 4 триггера/функции для поддержки новой логики замен тренеров и медиа-галереи.

**Что реализовать:**

1. **`cfr_reorder_media`** — функция смены позиции фото в админке
   - Один SQL-вызов вместо чтения-сдвига-записи на уровне приложения
   - Параметры: entity_type, entity_id, item_id, new_position

2. **`cfr_check_main_media`** — триггер `BEFORE INSERT/UPDATE` на `cfr_media`
   - Не более 1 `is_main=true` на объект
   - Не удалять главное фото, пока есть связанные записи

3. **`cfr_find_replacement_candidates`** — функция подбора кандидатов на замену
   - Ищет тренеров по тем же style_id ИЛИ по тому же залу
   - Возвращает UUID[]

4. **`cfr_auto_cancel_no_candidates`** — триггер `BEFORE INSERT/UPDATE` на `cfr_schedule_changes`
   - Если `change_type='replace'` и `replacement_candidates` пуст — автоподбор
   - Если кандидатов нет → автоотмена с причиной

**SQL-код:** уже описан в `new_format.md` раздел 11.3

**Связанные таблицы:** `cfr_media`, `cfr_schedule_changes`, `cfr_teacher_styles`, `cfr_entities`, `bridge_queue`

### Тикет 1.4-B: Content-Sanitization (раздел 9.2)

**Приоритет:** 🔴 Критический
**Сложность:** Низкая
**Описание:** Реализовать фильтр контента для `cfr_pages.content` и `cfr_visits.annotation`, `cfr_notes.text`, `cfr_messages.text`.

**Что реализовать:**
- Разрешить только markdown и HTML-теги без скриптов
- На уровне приложения (Node.js): `DOMPurify` или аналог
- На уровне БД: триггер `BEFORE INSERT/UPDATE` с regex-фильтром:
  - `<script[^>]*>.*?</script>` — удалить
  - `<style[^>]*>.*?</style>` — удалить
  - `on\w+="` — удалить
  - `style="[^"]*javascript:` — удалить
  - `style="[^"]*expression(` — удалить
