# 🤝 withLord — тикеты с обязательным участием пользователя

Сюда переносятся тикеты, которые **невозможно выполнить без пользователя**:

- SSH-доступ к серверу (сервер 192.168.1.85 в локальной сети, SSH извне недоступен —
  команды выполняет пользователь через свой SSH);
- git-мутации (commit/push) — **только по команде пользователя**;
- продуктовые решения, без которых тикет не двигается.

## Правила

1. В файле тикета обязательно указано: **что делает AI**, **что делает пользователь**.
2. AI подготавливает всё локально и выдаёт пользователю **готовую команду** для выполнения.
3. После выполнения пользовательской части тикет закрывается и переносится в `tickets/done/`.
