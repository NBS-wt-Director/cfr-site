# ARCH-005 — Визиты/лиды в PostgreSQL + «Статус» на контейнерно-pg метрики

> **Статус:** 📋 Запланирован (2026-11-14). Блокируется ARCH-003.
> Поставлен 2026-11-14.

## Постановка

Высоконаписущие сущности — на прямые SQL: пиксель посещаемости (S163) → `INSERT` в `visits`;
лиды форм (S151/S155) → таблица `leads`. Раздел «📟 Статус / 🚨 Проблемы» (S161/S164) —
на честные метрики контейнерного окружения. Опционально: `sharp`-оптимизация фото.

## ФАКТЫ

- Сейчас: `visits.json` кольцевой буфер (VISITS_MAX=20000, flush 1500 мс, дедуп 15000 мс),
  агрегатор `aggregateVisits()` — JS-циклы по массиву.
- `leads.json` — файл; `emailSent/emailError` (S155), журнал `logs/leads-email.log`.
- S161/S164 «Статус»: `df`, `pm2 jlist`, `pgrep nginx`, git-инфо — в контейнере
  показывают контейнер (частично закрыто `pid: "host"` в ARCH-001).
- NGINX `access_log off` — пиксель остаётся единственным источником посещаемости.

## ШАГИ

1. **Пиксель:** `GET /api/admin/track-visit` → `INSERT INTO visits`. Дедуп — SQL
   (`NOT EXISTS ... ts > now()-interval '15 seconds' and sid=…`) или в памяти (как сейчас) —
   зафиксировать выбор в журнале. Ротация: `DELETE` старых сверх лимита — раз в час.
2. **Агрегаты S163:** `aggregateVisits` → SQL (`count(*) filter (where ts > …)`,
   `group by page/section order by count desc limit 20`). Тесты: совпадение с JS-агрегатором
   на одном датасете.
3. **Лиды:** `lead-create`/`get-leads`/`save-leads` → таблица `leads` (анти-спам, emailSent —
   колонки). `leads.json` → разовый импорт (ARCH-002) → в trash.
4. **Статус:** карточки — размер таблиц pg (`pg_total_relation_size`), счётчики строк,
   соединения (`pg_stat_activity`), аптайм контейнеров (docker API/ENV), caddy-статус вместо
   nginx-строки, git-инфо — из тома. pm2-строка удаляется.
5. **Опционально (отдельным саб-шагом):** `sharp` + образ `node:22-slim`, роут
   `/img/{path}?w=…` для превью (менеджеры фото, плитки). При отказе — пункт закрывается «не делаем».

## КРИТЕРИИ ГОТОВОСТИ

- [ ] Пиксель пишет в pg; повторный заход (тот же sid+page ≤15 с) не создаёт строку
- [ ] get-visits/site-status отчёты (день/неделя/месяц/год, top-20 страниц, разделы) —
      SQL-агрегаты совпали с прежними JS-результатами на тестовом датасете
- [ ] Лиды: создание с формы, ✉️-колонка S155, CRM-таблица — через pg; файл не читается
- [ ] «Статус»: ни одной пустой/вводящей карточки в контейнерном режиме (pg-метрики вместо pm2/nginx)
- [ ] Ротация visits: таблица не растёт бесконечно (тест на превышении лимита)
- [ ] (если sharp) отдача превью <50 мс, оригиналы не перезаписываются
