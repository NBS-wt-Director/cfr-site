## Постановка (слова пользователя)

> «Посещаемость = заходы на сайт. Сохранять: IP-адрес, MAC-адрес (если возможно), referer (откуда перешли), URL страницы.»

## Что нужно

### 1. Пиксель на страницах сайта
- Небольшой `<script>` или `<img>` пиксель, который отправляет запрос на `/api/admin/track-visit`
- Передает: URL страницы, referer (если есть), язык браузера, разрешение экрана, timestamp
- IP и MAC определяются на сервере

### 2. Серверный учёт визитов
- **IP-адрес** — из `req.headers['x-forwarded-for']` или `req.socket.remoteAddress`
- **MAC-адрес** — доступен только на уровне ОС, из Node.js на сервере можно получить MAC сервера (не клиента). Для клиента — можно попробовать через `navigator.mac` (устарело) или не хранить.
- **Referer** — `req.headers.referer` или `req.headers.origin`
- **URL** — страница, на которой произошёл визит
- **User-Agent** — для определения устройства
- **Дата/время** — timestamp

### 3. Хранение
- `db.json` → `visits[]` — массив визитов
- Формат: `{ id, ts, ip, referer, url, userAgent, screen, language }`
- Ротация: хранить последние 10000 визитов, старые архивировать

### 4. API
- `POST /api/admin/track-visit` — пиксель, записывает визит
- `GET /api/admin/get-visits?period=day|week|month|year` — статистика

### 5. Статистика
- Общая: количество визитов за период
- По страницам: top-20 страниц за период
- По источникам: top-10 referer'ов
- По устройствам: User-Agent анализ
