# S149 — Мобильная шапка: кнопка «Заказать звонок» перенесена в меню ✅

> **Закрыт: 2026-11-09** (проверка: `npm run test-static`, тесты S149)

## Постановка (замечание администратора, проверка на мобильном)

Кнопка-бургер меню на мобильном есть, но **перекрыта кнопкой «Заказать звонок»** —
пользователь не может открыть меню.

Решение пользователя: в мобильной вёрстке перенести «Заказ звонка» в меню.

## Факты

- Кнопка звонка в шапке: `.header-actions .header-call-btn` (`header.js:153`).
- Бургер: `.mobile-toggle` рядом в `.header-actions` — на узких экранах кнопка звонка
  (с текстом, `white-space: nowrap`) вытесняла бургер за видимую область/перекрывала.
- В мобильном меню **уже была** своя кнопка звонка `.mobile-call` (`header.js:163`) —
  дублирование в шапке не нужно.

## Решение

Только CSS (`static/css/style.css`, блок в конце файла):

```css
@media (max-width: 767px) {
  .header-actions .header-call-btn { display: none; }
}
```

На ≤767px в шапке остаётся только бургер; заказ звонка — внутри открытого меню
(крупная кнопка `.mobile-call` над списком пунктов).
