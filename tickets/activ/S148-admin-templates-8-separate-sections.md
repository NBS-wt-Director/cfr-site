# S148 — Админка: подразделы «Шаблоны» — 8 отдельных разделов в сайдбаре

**Приоритет:** обычный
**Статус:** ✅ ИСПРАВЛЕН (2026-11-09)
**Найден:** 2026-11-09 (скрин пользователя: «зачем всё в одно место?» — жалобы на вкладки)

## Цель/постановка

Заменить вкладки внутри одной страницы на 8 отдельных разделов в сайдбаре:

1. Макеты
   - шаблоны.макеты_разделов_главной
   - шаблоны.макеты_разделов_сайта
   - шаблоны.макеты_сущностей
   - шаблоны.макеты_страниц
2. Текстовые маски
   - шаблоны.Текстовые_маски_сайта
   - шаблоны.Текстовые_маски_смс
   - шаблоны.Текстовые_маски_почты
   - шаблоны.Текстовые_маски_ботов_социальных_сетей

Все — заглушки с планом наполнения.

## Факты (до исправления)

- `S145` создал вкладки внутри `loadTemplatesSection`: «Макеты разделов/сущностей/страниц», «Текстовые маски», «Шаблоны писем/SMS».
- Пользователь: «зачем все подразделы запихнул в одно место?» — нужно 8 отдельных разделов, не 3 вкладки.
- `admin.html:sidebar-group-header="templates"` → одна ссылка «Шаблоны» → `loadTemplatesSection` → вкладки с `__switchTplTab`.

## Шаги (выполнено)

1. **Сайдбар:** 8 ссылок в группе «🧩 ШАБЛОНЫ» вместо одной. Иконки: 🏠/🧩/📦/📄 (макеты), 📝/💬/✉️/🌐 (маски).
2. **Реестр `sections`:** 8 записей `group: 'templates-stub'`, статус `skeleton`. Старая запись `id: 'templates'` удалена.
3. **Роутер `renderSection`:** ветка `section.group === 'templates-stub'` → `renderTemplatesStubSection(section)`. Удалён `if (sectionId === 'templates') loadTemplatesSection()`.
4. **`loadCurrentSection`:** редирект `#templates` → `#templates-mockups-home` (для старых закладок).
5. **`renderTemplatesStubSection(section)`:** по образцу `renderHelpStubSection`. Для каждого из 8 подразделов: иконка, lead-описание, план наполнения (todo-список). Внизу страницы — перекрёстные ссылки на остальные подразделы через `openSection()`.
6. **`openSection(id)`:** общий хелпер навигации (сайдбар + перекрёстные ссылки внутри страниц). Убрано дублирование подсветки.
7. **Удалено:** `loadTemplatesSection`, `window.__switchTplTab` (вкладки больше не нужны).
8. **Справка `admin-server.mjs`:** обновлена встроенная статья «Шаблоны» (DEFAULT_HELP_SECTIONS) — описаны 8 подразделов.
9. **Тесты:** переписан блок S142/S145 шаблоны → 27 проверок S148 (сайдбар, реестр, названия, group, удаление старого, роутер, TPL_STUBS, редирект, openSection, jsdom-рендер).

## Критерий готовности

- В сайдбаре группа «ШАБЛОНЫ ▸» содержит 8 подразделов.
- Каждый подраздел открывается отдельно, содержит заголовок, статус, описание и план.
- Внизу каждой страницы — перекрёстные ссылки на другие подразделы.
- Старый адрес `#templates` редиректится на первый подраздел.
- `loadTemplatesSection` и `__switchTplTab` удалены.
- Тесты зелёные (583/584, падает только S28 — известное).
