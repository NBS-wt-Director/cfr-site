## Постановка (слова пользователя)

> «В "настройки сайта" добавь раздел "статус" куда выводится полное состояние сайта + состояние сервера + посещаемость за день/неделю/месяц/год общая/по разделам/по страницам.
> Также:
> - в шапку админки добавить кнопку "Состояние сайта" (отражает цветом и цифрами текущее состояние, переводит в соответствующий раздел)
> - в статус добавить раздел "Проблемы" с подписями
> - раздел Статус при входе в админку всегда открыт
> - создать суперраздел "Информация"»

## Что нужно

### 1. Суперраздел «Информация»
- Новый раздел в сайдбаре админки (над «Настройки сайта»)
- Содержит подразделы: «📟 Статус» (всегда открыт), «🚨 Проблемы»
- Иконка: 📟 для Статуса, 🚨 для Проблем

### 2. Кнопка «Состояние сайта» в шапке админки
- В верхней панели админки (рядом с логотипом/названием)
- Отображает цвет: 🟢 зелёный = всё ОК, 🟡 жёлтый = предупреждения, 🔴 красный = ошибки
- Цифры: количество проблем, версий кэша
- Клик → переход в раздел «📟 Статус»

### 3. Раздел «📟 Статус»
- Состояние сайта:
  - Версия кэша `?v=47`
  - Количество слайдов / программ / тренеров / новостей / направлений
  - Размер `db.json` на диске
  - Размер `static/uploads/` на диске
  - Размер `static/data/` на диске
- Состояние сервера:
  - PID и uptime админ-сервера (port 3456)
  - Использование CPU / RAM процесса Node
  - Диск: свободно / занято (root, /home)
  - Память: total / used / free
  - NGINX: жив / мёртв (проверка 80/443)
  - Версия Node.js
  - Версия ОС
- Посещаемость (из S163):
  - Визиты за день / неделю / месяц / год
  - По разделам: главная / программы / тренеры / новости / расписание / цены / альбом / контакты
  - По страницам: top-20 страниц за период
- Всегда открыт при входе в админку

### 4. Раздел «🚨 Проблемы»
- Автоматическая диагностика:
  - Проверка: все ли CSS-классы на месте
  - Проверка: все ли JS-файлы загружаются
  - Проверка: все ли картинки в слайдах существуют на диске
  - Проверка: нет ли битых ссылок в базе
  - Проверка: размеры файлов (слишком большие?)
  - Проверка: целостность db.json (JSON.parse)
  - Проверка: доступность API маршрутов
- Каждая проблема с:
  - Иконкой (⚠️ / ❌ / ✅)
  - Описанием
  - Дату/время обнаружения
  - Кнопкой «Исправить» (если возможно)
