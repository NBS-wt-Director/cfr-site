# ARCH-007 — Переключение прода: DNS/Caddy, прогрев, откат

> **Статус:** 📋 Запланирован (2026-11-14). Финальный тикет волны ARCH.
> Блокируется ARCH-001…006. **Участие пользователя обязательно (SSH, DNS, NGINX/PM2).**
> Поставлен 2026-11-14.

## Постановка

Переключить центр-фр.рф с текущей связки (хостовый NGINX + PM2 + файлы) на
compose-стек (Caddy + app + PostgreSQL) без простоя и с гарантированным откатом.

## ШАГИ (с участием пользователя, работа на сервере — строго через него)

1. **Подготовка (без влияния на прод):**
   - compose-стек на сервере, порты 8080/8443 (или тестовый поддомен), NGINX/PM2 работают;
   - импорт актуальной прод-базы в pg (свежий sync-from-server, не недельной давности);
   - прогон ARCH-006 набора на проде-копии;
   - замер Lighthouse/SEO до переключения (база сравнения).
2. **Репетиция откатa:** `pm2 start cfrsite` поднимается за минуты (файлы на месте) — проверить
   заранее, зафиксировать команду откатa в журнале.
3. **Окно переключения (5–15 мин):**
   - финальный sync прод-данных → pg (в момент, когда админка закрыта для правок);
   - NGINX: `sites-enabled` → выключить (файл не удалять!), Caddy занимает 80/443;
   - `docker compose up -d` с боевым Caddyfile;
   - smoke: главная, program/trainer по slug (S18), заявка с формы + письмо (S155-фильтр Яндекса),
     404, sitemap/robots, админка (логин/CRUD/загрузка), пиксель (визит в pg).
4. **Наблюдение 48 ч:** логи Caddy/app/pg, «Статус» (ошибки/проблемы), сравнение посещаемости
   с базой дней, выборочная сверка страниц прод-скриншотами.
5. **Уборка (после 48 ч, отдельным шагом):** PM2-процесс `cfrsite` удалить, NGINX-конфиг —
   в резерв (не удалять), файлы-артефакты (`db.json`, `visits.json`, `leads.json`,
   `.admin-*`, `static/js/data/`, `export-static.mjs`) — в `trash/` (архив, не удаление).
   **Процедуру деплоя в этом тикете НЕ переписывать** — см. ARCH-008 (отложен).

## КРИТЕРИИ ГОТОВОСТИ

- [ ] HTTP 200 по https://центр-фр.рф извне, TLS-валиден (Caddy), редиректы www/80→443
- [ ] Smoke-список шага 3 — все зелёные на проде
- [ ] Откат репетирован и задокументирован (команда + время восстановления)
- [ ] 48 ч наблюдения без ошибок уровня error в «🚨 Проблемы»
- [ ] Прод-данные в pg = снимок на момент переключения (сверка счётчиков)
- [ ] Артефакты старой архитектуры убраны в trash/, NGINX-конфиг законсервирован
