# S162 — Батч-редактирование слайдера не сохраняет пакетом + кнопка «удалить скрытые»

> **Статус:** 🕐 В разработке (2026-11-12).
> Поставлен 2026-11-12.

## Постановка (слова пользователя)

> «Похоже в слайдере, если несколько изменений подряд — не сохраняется пакетом (обнаружено на ссылках). Возможно другая проблема, но я думаю что дело в этом.
> Нужно добавить кнопку «удалить скрытые слайды»»

## Проблема

### 1. Пакетное сохранение

При сохранении слайдера через `/api/admin/save-slides` используется `sanitizeSlides()`, который содержит критический баг:

```js
function sanitizeSlides(raw) {
  // ...
  for (const item of src) {
    const image = cleanMediaPath(item.image);
    if (!image) continue;  // ← БАГ: слайд без картинки выбрасывается
    // ...
  }
  return out;
}
```

Если при пакетном редактировании у одного из слайдов:
- картинка пустая или не прошла `cleanMediaPath`
- ссылка стала невалидной
- любой санитайзер вернул пустое значение

— слайд **полностью выбрасывается из массива** и **пропадает из базы**.

### 2. Кнопка «удалить скрытые слайды»

В редакторе слайдера в админке есть скрытые слайды (в сворачиваемой группе `<details>`), но нет кнопки для их массового удаления.

## Что нужно сделать

### Исправление пакетного сохранения

1. **Убрать `if (!image) continue;`** из `sanitizeSlides`
2. **Слайды без картинки** должны сохраняться с пустой `image: ''` и флагом `hidden: true`
3. **Визуальная индикация** в редакторе: слайды без картинки помечаются «🚫 без картинки»
4. **Сохранять все слайды** из запроса, даже если какие-то поля не прошли санитайзер (санитайзер ставит дефолты, а не удаляет)

### Кнопка «удалить скрытые слайды»

1. В секции «🙈 Скрытые слайды» добавить кнопку «🗑 Удалить все скрытые»
2. Подтверждение: «Удалить N скрытых слайдов? Это действие нельзя отменить.»
3. Удаление: `splice` из `slidesState` → `saveSlides()`
4. Слайды удаляются из базы и из статического экспорта

## Критерий готовности

- [ ] `sanitizeSlides` НЕ выбрасывает слайды без картинки/ссылок
- [ ] Слайды без картинки сохраняются как `hidden: true, image: ''`
- [ ] Кнопка «удалить все скрытые» работает в редакторе
- [ ] Удаление скрытых подтверждается и сохраняет в базу
- [ ] Тест на пакетное сохранение: 10 слайдов, изменение всех полей → все 10 сохраняются

## ЖУРНАЛ

- 2026-11-12: пользователь обнаружил что пакетное редактирование слайдов (особенно ссылок) не сохраняет изменения. Причина найдена: `sanitizeSlides` с `if (!image) continue` выбрасывает слайды без картинки.
