# S144 — Админка: строки тренеров — кнопка на всю ширину, нет ФИО

**Приоритет:** высокий  
**Статус:** ✅ ИСПРАВЛЕН (2026-11-09)  
**Найден:** 2026-11-09 (скрин пользователя)

## Цель/постановка

В разделе «👨‍🏫 Управление тренерами»:
- кнопка ✏️ «Редактировать» растянулась на всю ширину строки (синяя полоса);
- ФИО тренера не видно.

## Факты (диагноз)

**Оба симптома — от одной причины.** `admin.html:72`:

```css
.btn-primary { background: var(--primary); color: white; width: 100%; }
```

В строке `.entity-item` (flex-контейнер) кнопка `btn-sm btn-primary` (✏️)
получает `width:100%` — съедает всю ширину. Спан с ФИО
(`flex:1; min-width:0; overflow:hidden; text-overflow:ellipsis`, строка 5374)
сжимается до нуля → текст обрезан полностью.

Данные в БД корректны: API get-trainers отдаёт 13 тренеров с name.
Проверено flattenDb + curl.

## Шаги

1. Добавить переопределение CSS: кнопки внутри `.entity-item` / `.news-item`
   не растягивать (`width:auto`), не трогая общее правило btn-primary (модалки, save-кнопки).
2. Проверить все списки, использующие .entity-item (тренеры, программы, направления, залы).
3. Регресс-тест в test-static.mjs: btn-primary в строках списков не width:100%.

## Критерий готовности

- Строка тренера: ⠿ | 👁 | ФИО | категория | флаги | 👁 | ✏️ (компактная) | №N
- ФИО видно полностью (или с многоточием при переполнении).
- Тесты зелёные.
