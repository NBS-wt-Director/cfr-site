# S156 — Счётчики сабразделов в заголовках групп сайдбара

> **Статус:** 🟢 Локальная приёмка пройдена (2026-11-10). Ждёт деплоя на прод
> (общий деплой волны 7 вместе с S155). Поставлен 2026-11-10.

## Постановка (слова пользователя)

> «У каждого родительского раздела админки надо показать 2 цифры в заголовке —
> число активных сабразделов и число сабразделов-заглушек»

## ФАКТЫ

### Сайдбар (`static/admin.html`)
- Группы: `📦 ДАННЫЕ`, `🧩 ШАБЛОНЫ`, `⚙️ НАСТРОЙКИ САЙТА`, `📊 CRM`, `🤖 БОТЫ`,
  `🔗 ИНТЕГРАЦИИ`, `📖 СПРАВКА` — заголовок `.sidebar-group-header`
  с `data-group` и `onclick="toggleGroup(this)"`.
- Заглушки помечаются классом `sidebar-wip` (ссылки) и `status: 'skeleton'|'wip'`
  в реестре `sections`.
- `toggleGroup` (стр. ~1046) менял стрелку через `header.textContent.replace(/▸|▾/, ...)` —
  при наличии `<span>`-счётчиков это стирало бы их (textContent перезаписывает детей).

## РЕШЕНИЕ

### Счётчики
- `renderGroupCounts()` — вызывается один раз при загрузке (состав разделов статичен).
- Для каждой группы: считает `<a data-section>` в её `.sidebar-group-body`:
  с классом `sidebar-wip` → **заглушки**, без него → **активные**.
- Разметка заголовка: `«<исходный текст>» <span class="grp-arrow">▸/▾</span>
  <span class="grp-count grp-count-active">N</span>
  <span class="grp-count grp-count-stub">M</span>`.
- Исходный текст кэшируется в `header.dataset.base` — повторные вызовы идемпотентны.
- `toggleGroup` и `openGroupForSection` правят только `.grp-arrow`, не трогая счётчики.

### CSS
- `.grp-count` — inline-блок с закруглением; `.grp-count-active` — зелёный (#d1fae5/#065f46),
  `.grp-count-stub` — янтарный (#fef3c7/#92400e). `title` при наведении — «Активных
  подразделов: N» / «Подразделов-заглушек: M».

## Критерий готовности
- В заголовке каждой группы видны 2 цифры: активные | заглушки.
- Клик по заголовку сворачивает/разворачивает группу, стрелка меняется, счётчики остаются.
- `[М]` = 0 → показывается «0» (не скрывается).
- Тесты S156 зелёные.
