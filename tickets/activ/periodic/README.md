# 🔄 Периодические задачи

Задачи, которые выполняются **неоднократно** (по событию, по расписанию или по команде),
а не закрываются один раз. Файл тикета **не переносится в `done/`** — он живой регламент.

| Тикет | Когда |
|-------|-------|
| [deploy.md](deploy.md) | По готовности пачки изменений |
| [check.md](check.md) | Периодически / после правок |
| [test.md](test.md) | Перед каждым деплоем и после крупной пачки правок |
| [sync-data.md](sync-data.md) | Периодически: подгрузка данных с сайта (прод) и из CRM |
| [trash-cleanup.md](trash-cleanup.md) | По мере накопления мусора: неактуальные доки и код |

Правила: см. `tickets/README.md`. Каждая периодическая задача имеет чек-лист и
журнал выполнений внизу файла (одна строка = одно выполнение).
