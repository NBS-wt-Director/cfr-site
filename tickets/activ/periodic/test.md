```bash
cd cfr-site
npm run test-menu     # навигация/меню — эталон 26/26
npm run test-static   # jsdom-смоук статики — текущий эталон 455/456
```

## Правила

1. **Падение предсуществующее:** единственная разрешённая красная проверка — **S28**
   (3 программы без обложек: «Специальное ОФП (6-12 лет)», «Основы работы с оружием»,
   «Массаж внутренних органов» — на диске нет их папок с фото).
   Любая ДРУГАЯ красная проверка = регрессия, деплой запрещён.
2. Каждая исправленная баг-правка сопровождается **регресс-тестом** в `test-static.mjs`
   (обязательное требование S139 и протокола волн).
3. После правок клиентского JS — `node --check`, inline-JS админки компилируется.
4. Тесты не должны удалять/портить боевые данные: тестовые данные **откатывать**
   после смоука (бэкап `db.json` перед смоуком на изолированном порту, образец — `smoke-s125.mjs` :3461).

## Смоук API (round-trip)

- Сервер на изолированном порту (не трогать живой :3456 пользователя);
- Проверки: 401 без токена, round-trip сохраняемых полей, санитизация мусора;
- После — восстановление `db.json` / настроек из бэкапа.
