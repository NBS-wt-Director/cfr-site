# S18 — Якоря страниц по ФИО/названию

> **Статус:** ⚠️ Спорный — закрытие не подтверждено ЖУРНАЛОМ


## Цель

Ссылки на страницы программ/тренеров работают по ФИО/названию, не только по id.

## Шаги

1. `entity.js` — парсить URL: если `?id=имя-программы` или `?id=фио-тренера`, искать по `name` (не только по id)
2. Транслитерация: `Греко-римская борьба` → `greko-rimskaya-borba`
3. `export-static.mjs` — генерировать `navPrograms` и `navTrainers` с транслитом
4. Обновить все ссылки: `header.js`, `programs.html`, `trainers.html` — использовать транслит
5. Страница по транслиту → рендерит сущность по `name`
6. Несуществующий id/name → блок "Не найдено"

## Критерий готовности

`program.html?id=здоровая-спина` работает; `trainer.html?id=глазырин-михаил` работает; все ссылки транслитом.

## Примечание

Возможная частичная реализация: экспорт `navPrograms`/`navTrainers` существует, S120 делал ASCII-slug/транслит для страниц. Проверить фактическое состояние кода перед выполнением.
