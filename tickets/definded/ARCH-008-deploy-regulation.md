## Постановка

Действующий регламент деплоя (AGENTS.md, `tickets/activ/periodic/deploy.md`,
`deploy/ecosystem.config.js`, `scripts/deploy-merge-db.mjs`) описывает стек
«git pull → статическая генерация → pm2 restart + мерж db.json».
После ARCH-007 он неприменим: генерации нет, PM2 нет, база — PostgreSQL.

## Что должно войти (заготовки, не применять до разморозки)

1. **Новый регламент деплоя:**
   `git pull → docker compose build → migrate.mjs → up -d → smoke`
   (сборка образа или `node:22-alpine` + том — зафиксировать выбор).
2. **Бэкапы:** `pg_dump` → `backups/` (правило «все бэкапы в backups/» сохраняется;
   ротация 10 последних — тоже). `cp db.json` — долой.
3. **Мерж баз:** `deploy-merge-db.mjs` → `scripts/pg/merge-prod-to-pg.mjs`
   (тот же API `export-db` как источник; защита секретов S155 — перенести на
   строки settings.emailConfig).
4. **Обновить AGENTS.md:** разделы «Деплой», «База данных», «Частые проблемы»
   (502 → docker compose ps/logs; Turbopack/db.json-строки — в архив).
5. **periodic-тикеты:** `deploy.md`, `check.md`, `test.md`, `sync-data.md`,
   `trash-cleanup.md` — переписать чек-листы под compose/pg_dump/pg_isready.
6. **Откат:** `docker compose down` + `pm2 start cfrsite` (пока NGINX-конфиг в резерве)
   → позже чистый pg-откат из pg_dump.
7. README.md проекта — синхронизировать (правило «обновить перед деплоем»).
