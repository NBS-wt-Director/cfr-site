# NEXT-001: Возврат Next.js — три приложения на одной PostgreSQL в Docker

> Создан: 2026-11-07. Статус: 🕐 **ПЛАН** (ждёт старта).
> Решение пользователя от 2026-11-07: «Next версия вернётся в 3х экземплярах».

## Постановка (дословно, 2026-11-07)

> «next версия вернётся в 3х экземплярах — crm, api и web-морда собранная на дизайне
> static. всё будет связываться с одной psql и подниматься на docker.»

## Архитектура цели

```
                    ┌──────────────────────────────┐
                    │   PostgreSQL (Docker, 1 инст)│
                    └──────┬───────┬───────┬───────┘
                           │       │       │
              ┌────────────┴──┐ ┌──┴─────┐ ┌┴──────────────────┐
              │ CRM (Next.js) │ │ API    │ │ WEB-морда         │
              │ админ/менеджеры│ │ (Next/ │ │ (Next.js, дизайн  │
              │               │ │ Node)  │ │  = текущий static)│
              └───────────────┘ └────────┘ └───────────────────┘
                    всё поднимается одним docker-compose
```

- **CRM** — управление контентом, клиентами, расписанием (замена/расширение текущей админки).
- **API** — общий бэкенд (данные, загрузка, почта, авторизация).
- **WEB-морда** — публичный сайт: дизайн берётся **с текущего `static/`**
  (HTML/CSS/JS + `css/style.css` + страницы из README → компоненты Next.js 1 с в 1).
- **Одна PostgreSQL на все три** — схема общая; правило монорепо: все PostgreSQL — в Docker.

## Конвенции окружения при возврате (фиксирую заранее)

- **env-файлы** (`.env`, `.env.local`, `.env.production`) и **`.admin-sessions.json`**
  переезжают в **volumes / `env_file:` docker-compose** — из дерева git-репозитория
  исчезают полностью. До docker-переезда лежат в корне (Next.js/PM2/`node --env-file=`
  читают только корень — см. `AGENTS.md` → «⚙️ Конвенции окружения»).
- Фавикон — **из загруженного логотипа** (`settings.siteSettings.logo`), не статичный файл
  (решение пользователя 2026-11-07, см. [SEC-10](SEC-10-favicon.md)).
- `db.json` остаётся источником истины статики **до** этапа 6; после — только psql.

## Критерий закрытия плана
Все 7 этапов развёрнуты в тикеты и выполнены; `docker compose up -d` на сервере
поднимает CRM + API + WEB на одной psql; старый статический деплой отключён.
