> Структура разделена на мобильную и десктопную версии + интерактивная спецификация.

## Новые возможности (v6)

### 🌙 Тёмная тема
- Переключатель в тулбаре каждой страницы
- Сохраняется в `localStorage`
- Применяется ко всем компонентам: шапка, подвал, таблицы, карточки, формы

### 📋 Переключатель видов
- В спецификации: кнопки «Спецификация / Мобильная / Десктоп»
- Загружает соответствующий макет в iframe
- Сохраняет последний выбранный вид

### ⏱️ Таймер
- Показывает время, проведённое на странице
- Запускается/останавливается кнопкой в тулбаре
- Показывает минуты:секунды

### 🖨️ Печать
- Оптимизированные стили для печати
- Скрывает тулбары и навигацию
- Показывает только контент спецификации

### ⌨️ Горячие клавиши
| Клавиша | Действие |
|---------|----------|
| `D` | Переключить тему |
| `T` | Показать/скрыть таймер |
| `H` | Показать подсказку |
| `1` | Спецификация |
| `2` | Мобильная версия |
| `3` | Десктопная версия |
| `Esc` | Закрыть боковое меню |

### 📖 Раздел API (в спецификации)
- **POST** `/api/lk/auth` — авторизация (с примерами запроса/ответа)
- **GET** `/api/lk/profile?section=overview` — дашборд
- **GET** `/api/lk/profile?section=visits` — посещения
- **GET** `/api/lk/profile?section=payments` — оплаты
- **GET** `/api/lk/profile?section=family` — семья
- **PUT** `/api/lk/profile` — обновление контактов
- **GET** `/api/lk/birthday` — проверка ДР
- **GET** `/api/lk/homework` — домашнее задание
- Таблица общих ошибок API (401, 404, 429, 500)
