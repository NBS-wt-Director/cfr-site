# Личный кабинет — Реализация (Тикет 3.2)

> Реализация рабочего модуля сайта на основе макетов и спецификации из `lk-design/`

## Что реализовано

### API эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/lk/auth` | Вход по phone + agreement_number → JWT |
| GET | `/api/lk/profile?section=overview` | Дашборд (приветствие, ближайшая тренировка, статистика, последние визиты, ДР) |
| GET | `/api/lk/profile?section=visits` | История посещений с фильтрами и пагинацией (20 записей/страница) |
| GET | `/api/lk/profile?section=payments` | Оплаты и списания (с подтипами: Тренировка, Возврат, Окончание срока) |
| GET | `/api/lk/profile?section=family` | Список связанных лиц (Я / Дети) |
| GET | `/api/lk/profile?section=birthday` | Проверка дня рождения (±3 дня) |
| GET | `/api/lk/profile?section=homework` | Домашние задания (если есть) |
| GET | `/api/lk/profile?section=profile` | Профиль (legacy) |
| GET | `/api/lk/profile?section=subscriptions` | Абонементы (legacy) |

### Страницы

1. **Авторизация** — вход по номеру телефона + номеру договора
2. **Обзор (дашборд)** — сводка с:
   - Баннер именинника (если ДР в ближайшие 3 дня, БЕЗ кнопки)
   - Подвкладки (Я / Дети) — горизонтальный скролл
   - Ближайшая тренировка (дата, время, группа, тренер, зал)
   - Статистика (кликабельные карточки):
     - Остаток: ~N тренировок + сумма за 31 день
     - За 31 день: количество посещений
     - Бонусы: акционные бонусы
     - Оплачено / потрачено: обе цифры за 31 день
   - Последние 5 визитов (за 31 день)
   - Кнопка «Посмотреть все посещения»
3. **Посещения** — история визитов с фильтрами по месяцу/программе, пагинация 20 записей
4. **Оплаты** — история платежей с типами (Оплата, Пополнение, Списание)
5. **Сертификаты** — ⚠️ в разработке
6. **Абонементы** — ⚠️ в разработке
7. **Домашнее задание** — ⚠️ в разработке
8. **Дневник самоконтроля** — ⚠️ в разработке

### Дизайн

- Единая цветовая схема с сайтом (Indigo, Purple, Amber)
- Sidebar слева (280px) на десктопе
- Адаптивность (sidebar → topbar на мобильных)
- Аккордион «В разработке» (по умолчанию скрыт)
- Кликабельные карточки статистики (раскрываются по клику)
- Tooltips на карточках статистики

## Данные из БД

API использует таблицы PostgreSQL:
- `users` — пользователи ЛК (phone, name, agreement_number)
- `cfr_persons` — люди (ФИО, телефон, дата рождения)
- `cfr_clients` — клиенты (parent_person_id для семей)
- `cfr_accounts` — абонементы (остаток, статус)
- `cfr_visits` — визиты
- `cfr_transactions` — платежи и списания
- `cfr_schedule_entries` — расписание (ближайшая тренировка)
- `cfr_entities` — программы/группы
- `cfr_halls` — залы
- `cfr_tasks` — домашние задания
