🔌 14. API эндпоинты

Важно: Все эндпоинты возвращают JSON. Авторизация через JWT-токен в заголовке Authorization: Bearer <token>.

Авторизация

POST /api/lk/auth
Запрос:
{
  "phone": "+79000000000",
  "agreement_number": "0000"
}
Ответ (успех):
{
  "success": true,
  "token": "eyJhbGc...",
  "user": {
    "id": 1234,
    "name": "Иван Иванов",
    "phone": "+7 (900) 000-00-00",
    "agreement_number": "0000",
    "has_family": true,
    "is_birthday": false
  }
}
Ответ (ошибка):
{
  "success": false,
  "error": "Неверный номер телефона или номер договора"
}

Дополнительные эндпоинты

PUT /api/lk/profile
Описание: Обновление контактных данных пользователя.
Запрос:
{
  "phone": "+79000000000"
}
GET /api/lk/birthday?person_id=X
Описание: Проверка, есть ли у человека день рождения в ближайшие 3 дня.
Ответ:
{
  "is_birthday": true,
  "name": "Иван Иванов",
  "birthday_date": "2026-08-07",
  "days_remaining": 0
}
GET /api/lk/homework?person_id=X
Описание: Возвращает домашние задания ТОЛЬКО если есть активные задания от тренера.
Ответ (есть ДЗ):
{
  "has_homework": true,
  "assignments": [
    {
      "id": 1,
      "title": "Приседания",
      "description": "3 подхода по 15 раз",
      "video_url": "/videos/squats.mp4",
      "created_at": "2026-08-01",
      "completed": false
    }
  ]
}
Ответ (нет ДЗ):
{
  "has_homework": false
}
Важно: Если has_homework === false — раздел «Домашнее задание» НЕ показываем в меню.
