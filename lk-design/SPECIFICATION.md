## 1. АВТОРИЗАЦИЯ

### 1.1 Форма входа

**Заголовок:** «Личный кабинет» (везде на экране входа, без эмодзи)

**Логотип:** вместо эмодзи панды — `<img src="logo.png" alt="Логотип">` (28×28px)

**Поля:**
| Поле | Тип | Валидация |
|------|-----|-----------|
| Номер телефона | `tel` | +7 (XXX) XXX-XX-XX |
| Номер договора | `text` | Цифры, 1-6 знаков |

**Логика:**
- Вход по номеру телефона + номеру договора (НЕ по паролю!)
- Если неверно → сообщение «Неверный номер телефона или номер договора»
- Ссылка для звонка администратору: `+7 (902) 258-45-47`

**API:**
- `POST /api/lk/auth` — вход (phone + agreement_number → JWT)

**Дизайн:**
- Шапка сайта (SiteHeader) — общая, как на всех страницах
- Подвал сайта (Footer) — общий, как на всех страницах

### 1.2 Тестовый аккаунт

> **Для разработки и тестирования:**

| Поле | Значение |
|------|----------|
| Телефон | `+7 (900) 000-00-00` |
| Договор | `0000` |

Этот аккаунт доступен на всех окружениях (dev, staging, prod) для тестирования макетов и функционала.

## 2. ОБЩАЯ СТРУКТУРА

### 2.1 Шапка и подвал

- **Шапка сайта (SiteHeader)** — НАД всем ЛК. Логотип, заголовок, кнопка звонка, кнопка ЛК. Полностью перерисована по образцу страницы тренера.
- **Подвал сайта (Footer)** — ВНИЗУ всего ЛК. Контакты, навигация, соцсети. Полностью перерисован по образцу страницы тренера.

### 2.2 Меню — ВСЕГДА видно

- **Desktop (≥ 1024px):** sidebar слева (280px), всегда виден.
- **Tablet (768–1023px):** sidebar слева (240px), всегда виден.
- **Mobile (< 768px):** нижняя навигация (bottom nav), всегда видна. НЕ скрывается, НЕ гамбургер. **Сайдбар отсутствует.**

### 2.3 Мобильные карточки статистики — клик для раскрытия

- Карточки статистики на дашборде **кликабельны** (не hover — на мобильных нет наведения).
- При клике карточка раскрывается, показывая дополнительные детали.
- Внизу каждой карточки — индикатор «Нажмите для подробностей ▾» со стрелкой.
- Стрелка поворачивается при раскрытии.

### 2.3 Крупный текст для людей с плохим зрением

- Базовый размер: **18px** (вместо стандартных 16px)
- Минимальная высота кнопок: **48px** (рекомендация WCAG)
- Поля ввода: **18px** шрифт, **50px** высота
- Фильтры: **50px** высота

### 2.4 80% клиентов — только телефон

- Bottom navigation на мобильных (всегда видна)
- Крупные кнопки (минимум 48px)
- Минимум кликов для навигации

## 3. ВКЛАДКИ (Основные разделы)

### 3.1 📊 Обзор (дашборд)

**Блоки:**
- Приветствие (аватар, имя, телефон, договор)
- Ближайшая тренировка (дата, время, группа, тренер, зал)
- Статистика: абонемент, посещения, бонусы, всего оплачено
- Последние 5 визитов
- Кнопка «Посмотреть все посещения»
- **Баннер именинника** (если ДР в ближайшие 3 дня) — **БЕЗ кнопки «Записаться»**

### 3.2 📅 История посещений

**Поля таблицы:**
| Колонка | Описание |
|---------|----------|
| Дата | Дата + время визита |
| Программа | Название группы/тренировки |
| Тренер | **Только имя** (без фамилии/отчества) |
| Зал | Название зала |
| Тип | Групповая / Персональная |
| Стоимость | Стоимость визита — **всегда указана**, не «—» |

**Фильтры:**
- По месяцу
- По программе

**Пагинация:** 20 записей на страницу

**Мобильная версия:** таблица показывает 3 колонки (Дата, Программа, Стоимость). Строка кликабельная — по нажатию раскрывается карточка с деталями (дата, программа, тренер, зал, тип, стоимость). Остальные строки остаются на месте, не смещаются.

### 3.3 💰 Оплаты и списания

**Поля таблицы:**
| Колонка | Описание |
|---------|----------|
| Дата | Дата операции |
| Тип | Оплата / Пополнение / Списание (с подтипом) |
| Сумма | Сумма (зелёный / красный) |
| Описание | Назначение |
| Статус | Завершён |

**Типы списаний (обязательно разделять):**

| Тип списания | Описание | Пример описания |
|-------------|----------|-----------------|
| `Тренировка` | По конкретному посещению | «Кунг-фу · 04.08.2026» |
| `Возврат` | Возврат средств | «Возврат за пропуск» |
| `Окончание срока` | Истёк срок абонемента | «Абонемент „Кунг-фу" 12 занятий — истёк» |

**Цветовая индикация:**
- **Оплата / Пополнение** → зелёный `+X ₽`
- **Списание (тренировка)** → красный `-X ₽`
- **Возврат** → зелёный `+X ₽` (с пометкой «Возврат»)
- **Окончание срока** → серый/оранжевый (информационное)

**Итого:** Всего оплачено, всего потрачено (31 день), баланс депозита

**Мобильная версия:** строки кликабельные — по нажатию раскрывается карточка с деталями (дата, тип, подтип, сумма, описание, статус). Остальные строки остаются на месте.

## 4. ПОДВКЛАДКИ (для родителей)

### 4.1 Логика отображения

**Показываем ТОЛЬКО если есть семья:**

| Подвкладка | Условие | Источник в БД |
|------------|---------|---------------|
| Я | Всегда | cfr_persons текущего пользователя |
| Дети (каждый) | Если есть дети у клиента | cfr_persons.parent_person_id_1/2 → children |

**Сородитель НЕ показывается.** Только текущий пользователь и его дети.

**Если семьи НЕТ** — подвкладки **НЕ показываем**. Просто раздел без подвкладок.

### 4.2 Поведение

- Подвкладки: горизонтальный скролл
- Активная подвкладка подсвечена
- Переключение перезагружает данные для выбранного человека

### 4.3 ⚠️ ВАЖНО: Отображение имён в подвкладках

**Внешний вид:**
- Вкладки людей показывают **ТОЛЬКО имена** (без фото/аватаров)
- Кнопки листания ← → остаются

**Пометка для бэкенда (рендеринг):**
> У большинства записей ФИО хранится целиком в поле «Фамилия» ИЛИ в поле «Имя». При рендеринге нужно:
> - Если в поле «Имя» пусто → брать из «Фамилии» (и наоборот)
> - В макете сейчас: «Я», «Сородитель», «Миша», «Катя» — это заглушки
> - На продакшене: рендерить то, что есть в БД, не терять данные

## 8. ДАШБОРД — ДАННЫЕ И ПОДСКАЗКИ

**Текст приглашения:** «Приходи на тренировку в течение 3 дней и получи подарок!»

- API: `GET /api/lk/birthday?person_id=X`

### 8.2 Статистика на дашборде

| Карточка | Что показывать | Подсказка (tooltip) |
|----------|---------------|---------------------|
| **Остаток** | `~ N тренировок` (снизу — суммарно за 31 день в рублях) | «Точное количество зависит от цены программ, на которые вы ходите» |
| **За 31 день** | Количество посещений за последние 31 день | «Последние посещения за 31 день. За весь срок: 48» |
| **Бонусы** | Акционные бонусы (руб.) | «Акционные бонусы по акции „Приведи друга". Начисляются за каждого приведённого друга» |
| **Оплачено / потрачено** | **Обе цифры видны сразу:** `3 140 ₽ / 2 400 ₽` — оплачено (положено на счёт) и потрачено (по тренировкам) за 31 день | «Оплачено — положено на счёт, потрачено — по тренировкам» |

### 8.3 Последние посещения (на дашборде)

- Показывать **только посещения за последние 31 день**
- Tooltip: «Показаны посещения за последние 31 день. Полная история — во вкладке «Посещения»»

### 8.4 ПОМЕТА ДЛЯ БЭКЕНДА — бонусы

> Акционные бонусы по акции «Приведи друга». Нужен отдельный API-эндпоинт для расчёта бонусов. Данные хранятся отдельно от обычных начислений.

## 11. ИТОГОВЫЙ ПУТЬ ПОЛЬЗОВАТЕЛЯ

```
1. Открывает /lk
2. Видит шапку сайта + форму входа + подвал сайта
3. Вводит телефон + договор → нажимает «Войти»
4. Попадает на дашборд (обзор)
   ├── Шапка сайта (всегда видна)
   ├── Меню (всегда видно: слева на десктопе, снизу на мобильном)
   ├── Подвал сайта (внизу)
   ├── Если ДР: баннер-поздравление (без кнопки)
   └── Если родитель: подвкладки (Я / Дети)
5. Переключается между вкладками через меню
6. Заглушки показывают что будет (без сроков)
7. Выход через кнопку в меню
```
