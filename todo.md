## 📋 ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

Веб-сайт для центра функционального развития "Шифу Панда" (г. Екатеринбург). Сайт включает публичную часть для посетителей и административную панель для управления контентом.

---

## 🌐 ПУБЛИЧНЫЕ СТРАНИЦЫ

### 1. Главная страница (`/`)
- `SiteHeader` - шапка сайта
- `HomeSlider` - слайдер
- Секции: расписание, цены, программы, тренеры, новости
- Разделитель между секциями (настраиваемый)
- `Footer` - подвал с навигацией и контактами

### 2. Программы (`/programs`)
- Каталог программ тренировок

### 3. Программа детально (`/programs/[id]`)
- Детальная страница программы

### 4. Тренеры (`/trainers`)
- Список тренеров и персонала

### 5. Тренер детально (`/trainers/[id]`)
- Детальная страница тренера

### 6. Расписание (`/schedule`)
- Страница расписания

### 7. Контакты (`/contacts`)
- Контакты и карта

### 8. Новости (`/news`)
- Страница новостей с фото и видео

### 9. Ручные страницы (`/[slug]`)
- Динамические страницы с Markdown/HTML

### 10. Личный кабинет (`/lk`)
- Страница личного кабинета

## 📂 ДОПОЛНИТЕЛЬНЫЕ ФАЙЛЫ ДАННЫХ

### data/pages.json - Ручные страницы
```json
[
  {
    "id": "obuchenie",
    "slug": "/obuchenie",
    "title": "Обучение",
    "content": "Текст страницы",
    "media": "/uploads/page-media.jpg",
    "enabled": true,
    "code": "## Markdown код",
    "order": 1
  }
]
```

### data/footer.json - Настройки футера
```json
{
  "enabled": true,
  "showContacts": true,
  "showSocial": true,
  "showCopyright": true,
  "copyrightText": "© 2026 Шифу Панда",
  "links": []
}
```

## 🔧 API ROUTES

| Маршрут | Описание |
|---------|----------|
| `/api/db` | База данных |
| `/api/programs` | Программы |
| `/api/trainers` | Тренеры |
| `/api/employees` | Сотрудники |
| `/api/workouts` | Тренировки |
| `/api/news` | Новости |
| `/api/pages` | Ручные страницы (включенные) |
| `/api/pages/[slug]` | Страница по slug |
| `/api/upload` | Загрузка файлов |
| `/api/send-email` | Отправка email |
| `/api/admin/pages` | Управление страницами |
| `/api/admin/footer` | Настройки футера |
| `/api/admin/stats` | Статистика |
| `/api/autoupload` | Автозагрузка |
